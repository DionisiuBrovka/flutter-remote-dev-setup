# Настройка сервера для удалённой Flutter/Android-разработки

Сервер: Ubuntu Server 24.04 (headless). Все шаги запускаются **от обычного
пользователя** (не root), `sudo` вызывается внутри сам.

## Перед началом

1. Положи все файлы в одну папку на сервере.
2. Сделай их исполняемыми:
   ```bash
   chmod +x *.sh
   ```
3. Открой `00-env.sh` и впиши свои данные: `GIT_USER_NAME`, `GIT_USER_EMAIL`,
   и `PROXY_URL` (если нужен прокси).

## Порядок запуска

```bash
./01-base.sh         # пакеты + JDK 17
./02-flutter.sh      # Flutter SDK
./03-android.sh      # Android SDK + лицензии
./04-usb.sh          # доступ к USB (после него ПЕРЕЛОГИНЬСЯ!)
# здесь выйди из ssh и зайди заново
./05-proxy.sh on     # ОПЦИОНАЛЬНО — прокси (см. ниже)
./06-github.sh       # gh + git + авторизация (токен)
./07-claude-code.sh  # Claude Code
./08-finish.sh       # проверка + шпаргалка
```

После `04-usb.sh` нужно **выйти из ssh и зайти снова** (или перезагрузить
сервер) — иначе группа `plugdev` не применится и `adb` не увидит телефон
без root.

## Про прокси (шаг 05)

Шаг опциональный. Включить/выключить:
```bash
./05-proxy.sh on
./05-proxy.sh off
```
Настраивает прокси сразу для shell, apt, git и npm.

**Важно:** если интернет на сервере доступен только через прокси — запусти
`./05-proxy.sh on` **первым**, до `01-base.sh`, иначе apt не достучится до сети.
Предполагается обычный HTTP/HTTPS-прокси.

## Идемпотентность

Все шаги можно запускать повторно — уже сделанное пропускается, блоки в
`~/.bashrc` не дублируются.

## После установки

- VS Code на ноуте: Remote-SSH к серверу, расширения Flutter+Dart ставишь
  «в SSH», открываешь проект, `F5`.
- Экран телефона — scrcpy на ноуте через SSH-туннель (команды печатает
  `08-finish.sh`).
